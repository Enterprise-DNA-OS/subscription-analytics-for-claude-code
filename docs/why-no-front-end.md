# Why no front end

A monthly subscription review needs records, calculations, evidence and follow-up. The operator asks Claude Code, Codex, OpenCode or Cursor for the result; the agent runs the documented CLI. Branded read-only HTML is the view.

This base has no interactive dashboard, mobile interface, drag and drop, customer portal or hosted collaboration. It runs locally without internet after dependencies are installed, but that is not a mobile offline sync service. Reports are snapshots; regenerate them after records change. Someone must supply fresh monthly exports. Billing connections, invoice normalisation and automatic notifications need separate implementation.

Enterprise DNA can build an agreed front end, connections or another stack into a custom version and operate it through Omni by Enterprise DNA. One setup fee, then a retainer.
